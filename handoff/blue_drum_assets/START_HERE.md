# CANIS dark-blue drum handoff

1. Extract the ZIP and open `blue_drum_studio.usda` in Isaac Sim 6.2.
2. Read `sample_catalog.json` for the four prims and their intended conditions.
3. Give the extracted pack and `AGENT_TRAINING_PROMPT.md` to the training agent.
4. Use `docs/dataset_generation_handoff.md` for the studio pipeline and `docs/yolo26s_training_serving.md` for training and serving. The original warehouse handoff and yellow baseline release notes are also included for reference.

The blue preview contains four blue and zero yellow drums. The earlier studio release contains 1,200 yellow images. For a matched comparison, the agent brief proposes a 1:1 ratio by image count in each split, subject to pilot review.
